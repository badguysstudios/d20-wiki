# D20 Deathmatch Wiki

Fan wiki for **D20 Deathmatch** (Bad Guys Studios). Live site: https://badguysstudios.github.io/d20-wiki

## Editing
- Every page is a Markdown file in `content/`. Link pages with `[[Page Name]]`.
- Edit a file on GitHub (pencil icon) and commit. The site rebuilds automatically in about a minute.
- Or open this repo as an **Obsidian** vault with the Obsidian Git plugin.

## Folders
- `content/Characters`, `content/Places`, `content/Lore`: hand-written lore pages
- `content/Episodes/<Season>`: one page per episode
- `content/private/` is never published (ignored by the site and by git). Keep DM-only notes there.
